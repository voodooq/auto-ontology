# 锚定源数据的本体建模（Source-grounded ontology modeling）

> 本文档为 [`skills/nvidia-ontology-management/references/modeling.md`](../../../../../skills/nvidia-ontology-management/references/modeling.md) 的简体中文翻译版。

当需求涉及**改变业务含义**（而不仅仅是文字润色）时，请使用本工作流。常规 API 调用细节见 [write-api.md](write-api.md)；模型发布、晋级与回滚请遵循 [publication.md](publication.md)。

## 从问题契约出发

在提出任何模型修改前，先记录典型业务问题及其所要求的统计总体（Population）、指标（Measure）、分组维度、时间范围、对比基准与排除条件。利用导出的物理数据目录以及经审核的源数据证据核查表结构、字段类型、键、可空性、时间列及关联关系。**字段名称与少量样本值仅作辅助参考，绝不能作为实体标识或基数（Cardinality）的证明。**

按业务身份与统计总体来定义每一个概念。名称相近或当前行集合碰巧相同，并不意味着两个概念等价。每个属性都必须具备明确的物理来源或显式的派生公式。编辑现有模型时务必保留物理 ID 与语义 ID——自动生成的 UUID 不能当作自然名称的 Upsert 键使用。

## 关系契约

每条语义关系记录都应明确：

- 源概念与目标概念及其对应的物理列；
- 关联方向与业务角色；
- 预期的一对一（1:1）、一对多（1:N）或多对多（M:N）多重度；
- 键/空值行为及实测的连接覆盖率；
- 经批准的查询方向与已知的扇出（Fanout）风险；
- 有效期、版本及源数据证据。

**列名相同并不等于可以安全 Join。** 必须测试重复键、空键、反向连接、缺失映射与基数违例。此外，一条语义关系并不会自动成为预测图边、知识图谱边或求解器系数。

## 指标契约

每个可复用的指标记录都应明确：

- 表达式与源数据证据；
- 底层行粒度（Row grain）与允许的查询/分组粒度；
- 物理单位（需与时间粒度区分记录）；
- 可加性维度（Additive dimensions）与禁止二次聚合的场景；
- 分子、分母、权重与统计总体过滤条件；
- 空值、空总体以及分母为零时的处理行为；
- 生效时间（Effective time）、可用时间（Availability time）、修订版本、有效期与替代关系（Supersession）。

数量（Quantity）、比例（Fraction）、周期均值（Period average）、比率（Rate）与区间总计（Horizon total）属于截然不同的指标类型。**总和之比（Ratio-of-totals）通常不等于比率均值（Mean-of-ratios）。** 运行级别（Run-level）的汇总值在与一对多明细表 Join 后严禁直接求和。

业务策略需要明确的授权来源、适用范围、受限字段、允许变更项与必需标识。描述性文本本身不构成可执行流程或授权凭证。

## 将设计映射到受支持的 Auto Ontology 操作

始终采用受支持的最小粒度变更：

- 修正元数据描述时，对已有 `Term` 或 `ColumnAttribute` 执行 `PATCH`；
- 新增或更新可复用的派生表达式时，先校验再创建/更新 `SQL attribute`；
- 涉及概念总体边界或表间关系变更时，使用指定作用域的原生模型导出/导入。

Auto Ontology 目前没有公开的“直接创建空 Term”端点，也没有完整的直接修改结构性关系的独立工作流。**切勿臆造不存在的接口。** 如果所设计的语义模型无法通过当前安装版本的公开 API 表达，请如实返回“模型能力缺口（Model gap）”，不要为了迁就接口而削弱业务设计。

## 交接前的验证

使用有源数据支撑的正例与反例进行测试，重点排查重复键/空键、扇出放大、反向连接、映射缺失、过期版本、模糊时间区间、单位混淆以及预期的空结果总体。确认作用域内的每个业务问题都能在不改变实质业务含义的前提下得到回答。

交付清单应包含：

- 版本化的语义规格说明；
- 精确的源表/列与 ID 映射；
- 关系契约与指标契约；
- 经批准的 Join 路径；
- 正向与负向测试用例；
- 尚未解决的模型或产品能力缺口。

**SQL 执行成功、导入接口返回成功或查询返回非空结果，都不足以证明语义正确。** 请将审阅后的规格交付给 [publication.md](publication.md) 发布流程，以完成备份、分阶段应用、精确回读与回滚预案。
